# Public SG3 algorithm reference

`game_lab/sg3.cpp` adapts format/decoding algorithms from [citybuilding-tools sgreader](https://github.com/bvschaik/citybuilding-tools/tree/ea749c6e8bfa14ccb2ce5f1565b8f0501124a053/sgreader), commit `ea749c6e8bfa14ccb2ce5f1565b8f0501124a053`. This is independent modern parser code, not original Emperor code. Qt code is not linked; bounds checking and premultiplied output are authored here. Retain the following MIT notice.
