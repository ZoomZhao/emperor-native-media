# 当前自写玩法与继续范围

本增量直接完成可选仓储v4：粮食实际存于各仓、每仓600担、农庄经四邻道路入仓；断路/满仓损耗计账，接回后恢复。默认v3和现有三关保持原平衡，v1/v3普通读档不转换；v3自由城可明确付60贯把≤600担旧粮搬入一仓，失败保留整个旧城。规则/API见[WAREHOUSE_ROADS_API.md](WAREHOUSE_ROADS_API.md)，玩法与证据见[WAREHOUSE_ROADS.md](WAREHOUSE_ROADS.md)。

Release/UBSan各663仓储检查通过，含库存守恒、断路恢复、容量/无工/无仓、转换失败与24月保存续跑；服务各2634、预测各244和36月对照、旧城各203、完整挑战各1039回归通过。三关仍4/7/9月可达，实际窗口按本增量验收解释，构建通过不代表全部UI通过。

当前继续做自写玩法，不切回通用媒体测试。接下来三项有用任务：

1. **库存搬迁和多仓转换。** 当前非空仓不能拆，旧城转换只支持单仓≤600担。通过标准：每次成功/失败可核对全城库存，无超限或隐式丢粮，取消保留旧城，保存后同操作续跑一致。
2. **独立仓储训练关。** 现有三关继续v3，本轮没有v4挑战。通过标准：真实v4空城路线在期限内可达，容器绑定城市/原期限/结果，损坏混段不改活动城，原三关回归保持。
3. **路网原因和范围标记。** 显示选中农庄可达的仓、断点和余量。通过标准：自造斜角/绕路/多入口/多分量图与独立四邻期望一致，建拆即时刷新、不残留旧标记，有限窗口操作和提示可读。

历史报告记录的是具体原二进制执行/指令探测动作被工具拒绝；本轮不重试这些动作或换会话继续同一动作。这个记录不能概括成所有读取、反编译或整个恢复任务都禁止。当前选择自写玩法和自造输入，没有读取EXE、旧Swift或GameData、执行原游戏/衍生库；GameData仍在本地忽略范围。

本轮没有新的工具审批拒绝，测试或定位辅助失败按具体日志说明，不算通过，也不扩大成平台功能禁止。没有安装、改设备、真实发声或上传资源/截图/二进制。听觉、物理设备恢复、有效Bink、原版玩法/存档兼容仍未验证。
