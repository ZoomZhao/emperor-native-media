# 地图缩放、平移与验收状态

当前源码加入1x至8x缩放、四向平移、拖动平移和全图复位。默认4x显示左上32×32格，地图裁剪、地块点击和农庄路网标记共用同一个MapViewport。视口属于显示状态，不写入城市存档，也不改变自写城市规则。

缩放优先保持可见选中格的位置；没有可见选择时以视野中心为锚。箭头移动四分之一视野，原点限制在地图内。拖动模式只移动视图，切换建设工具会退出。新建、开始挑战和成功载入恢复4x初始视图；失败载入保留当前状态。无效点、零/负窗口尺寸、非有限数与视野外标记按声明拒绝；右/下边界不产生128号越界格。
