# 自写城市 App 的真实窗口验收

2026-10-11。仅运行明确源码打包的 EmperorApp，指定隔离的完全自造资源目录；没有读取 GameData、运行原游戏或衍生库。默认静音始终保留，没有声音/设备设置、权限申请、强杀或 ang 会话操作。

## 发现与修复

在 macOS 自动将默认窗口适配到 1024×807 时，城市 HUD/地图表头和影片标题覆盖导航；建造工具长名称被截断。城市和影片现在按实际内容高度定位，保留缩放锚点，HUD 分两行，工具短名完整显示且费用保留在提示中。最终 AX 中导航底边为 99、城市 HUD 顶边为 125，截图确认分离。

城市称号显示为 `[]`：同一自造 UTF-8 中文字符串经 NSString `%s` 得到空文本，显式 UTF-8 转换与 `%@` 才保留文字。称号、勘查和营建消息采用明确转换。暂停时原定时器每 0.25 秒重写事件栏，覆盖勘查结果；现在只在月份变化时刷新模拟 HUD，暂停勘查保持可读。城市规则、存档格式、图形内核和媒体后端未改。

## 权限与结果边界

同一只读探针在沙箱中三项预检不可用，在主机执行环境中 AX、窗口捕获及事件发送均现成可用。没有请求新权限或修改设置；没有工具审批拒绝。截图用 ScreenCaptureKit 只捕获登记窗口，不截桌面或其他应用。

辅助程序的模态 AX 回复超时、定向鼠标投递未奏效和路径编辑器输入差异单独保留，未当成产品缺陷或成功。最终使用标准窗口输入及 AX 控件，核对原生路径字段后只保存到新建测试目录；失败动作未通过重复打开面板或内部模型调用冒充完成。

这证明上述有限真实窗口路径，不证明原版兼容、全部资源、全部窗口尺寸、人工物理拖动/键盘、完整视觉或听觉。影片 seek 是 AX 操作，本轮未等待完整 EOF，也未测试真实发声或物理设备恢复。旧“只构建/无 GUI”是此前阶段结果；当前执行范围见 [EXECUTION_SCOPE.md](EXECUTION_SCOPE.md)。

实例记录的 `launch_time` 为 0：此启动方式下 NSRunningApplication 未返回可用 launchDate，不能声称独立启动时间校验通过。操作仍按本次 NSTask 的 PID、精确 bundle 路径/标识、主窗口标题与前台条件限定，正常退出回执绑定同一 PID。后续辅助程序应明确拒绝缺失的启动时间，或采用可靠的进程创建时间凭据。地图表中的文件名来自 App 静态列表，本轮没有选取原地图或读取 GameData。
