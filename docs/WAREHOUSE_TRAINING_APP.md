# 官仓通路的 App 与完整存档接线

主线在自写“官仓通路”模块之外接入第四个菜单项，原三项数组不变。明确开始/重试创建暂停的空白仓储v4候选城；持久runId分配成功且模块begin成功后，城市与会话一起提交。人口0、初仓400/600担、5000贯，没有额外资源奖励。当前目标和24个月期限来自捕获的关卡配置；训练提示使用同一次城市快照，目标仍只取原四项，没有隐含的满仓/拆路步骤要求。

ECG1版本1保留原v3挑战城市长度65580；版本2仅允许131152字节v4城市与id4/revision1训练配对。二者都包含52字节头、完整城市、72字节ECS1、ECA1收据册；校验和覆盖头部长度/version和三个完整段，拒绝混段及尾随。新读取上界164056字节覆盖满4096条收据的v4挑战，不能用自由城131152字节上界代替。

载入先在候选中校验格式、城市规则、训练注册revision、ECS1日期/结果与收据合并，再restore原runId、起始月、期限、目标和结算记录，所有对象同时提交。失败不改城市、会话、收据或活动期限；不重新begin、不使用sidecar。保存观察实际当前月，候选解码预验后同目录临时文件并原子替换。有效替换目标/期限从存档恢复，不重新套默认目录配置。

ECG1完整SHA-256用于检测意外改写/混段，不是身份签名；不保证抵抗有意重算摘要的编辑、断电或外部并发改写。通关收据留在当前会话及完整保存中，载入与当前已有册取并集，旧通关前档同runId再赢不发第二个事件。既有App持久runId计数器保持；尚无跨App全局通关档案、徽记展示或资源奖励。

主线新增文件回归验证真实确定路线19月胜利、三条24月失败、37个实际文件检查点与新实例未来续跑；涵盖满仓/断路/重连/胜负、旧档与替换目标期限、同月异城/元数据/收据混段、错误规则/revision/version/长度/非法库存和失败原子保留。原三关整档套件另行验证4/7/9月和1039项合同。既有最终源码记录为模块2039、完整文件1003、原三关1039项，在Release/UBSan各通过；App另有构建与签名通过记录。此次发布仅核对报告与源码指纹，没有重新运行测试。模块作者的旧报告仍只对应当时的内存恢复范围。

原生窗口验收尚未全部闭合。已有断路档131288字节和胜利档131296字节保存/载入/另存逐字节一致；到期失败档已保存，但失败档恢复、同月混段的窗口拒绝及最终正常退出没有成功收据。存档辅助停在原生文件面板行选择保护，最后错误为`native scroll maximum absent`；保留失败日志，不把模型拒绝或文本提示计作这些窗口验收通过。后续可在获准的自写App验收任务中补齐，当前源码与冻结版本一致。
