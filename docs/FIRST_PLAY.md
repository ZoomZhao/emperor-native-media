# 第一次游玩

本地 App：`/Users/zoomzhao/Workspace/emperor-native-media/game_lab/build-playable/EmperorApp.app`。在 Finder 双击打开。默认直接显示暂停的自写城市，不需要选择资源目录、命令行参数或预制存档。默认静音，所有营建与挑战规则均为本项目自写原型。

2026-10-11发布状态：上述固定包仍为已完成首玩验收的`cd5fe03`版本，显示全图。以下缩放/平移说明适用于当前源码及候选包；候选的几何测试与构建已通过，完整窗口验收待完成，尚未替换固定包。见[视口验收状态](MAP_VIEWPORT.md)。

1. 在左侧关卡下拉框选“聚落初成”，点击“开始挑战”；出现新空城、目标与原期限。
2. 在上方选择“民居”，在平原上六个不同的空格各点一次；若提示格子已有建筑，换一格。每户15贯。
3. 保持暂停，点击“+1月”四次，观察左侧目标和人口变化；六户路线可完成这一关。也可选1x连续推进，再切回暂停。
4. 点击“仓储新城”可进入自由仓储城：初始官仓400担，新增农庄须通过上下左右道路连到官仓。勘查农庄查看黄色道路、青框官仓和当前余量。选择工具后点击空地建设，拆除收2贯；有粮官仓须先搬空。
5. 点击“保存城邑”选择自己的存档位置；以后点击“载入城邑”继续。同一关的原期限和结果一起保存。新建空城/仓储城或开始另一关会替换当前活动城，先保存再切换。

地图为128×128格，默认4x显示左上32×32格。用“+ / −”在1x至8x之间缩放；箭头平移四分之一视野。“拖动平移”开启后拖动地图移动视图，期间不建设；再次点击或切换营建工具退出平移。“全图”恢复1x全图并退出拖动。新建、开始挑战和成功载入重置为4x初始视图，城市存档不保存视口。窗口大小改变后地图、点击和路网标记使用同一转换。官仓通路为第四项24个月训练关，原三关仍采用原自写v3规则。没有原游戏逻辑/存档兼容、原版图片或声音；包内仅自写空资源目录和来源/玩法说明。双击启动不读取项目GameData。构建产物仅本地保留，私有远端只发布源码与说明。

开发重建：从明确源码运行`game_lab/app/build.sh`到全新绝对输出目录，再按来源清单复制到上述固定位置；不要把构建产物加入Git。构建脚本不读取原资产，App要求macOS15及以上。
