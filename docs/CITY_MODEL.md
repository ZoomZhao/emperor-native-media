# 自写城市模型与 App 集成

2026-10-11。ang 的 `CitySimulation` 已纳入正常 App 构建；无需启用演示宏。这是可以继续发展的自写城市营建功能。规则没有与原游戏对比，当前不声称原版行为一致或完整复刻。源码适用仓库 MIT 许可证，App 包内保留 LICENSE 与生产源码 SHA-256 清单。

## 实现与验收范围

128×128 网格支持道路、住宅、农庄、水井、宗庙、集市、更楼和拆除。初始国库 5000、存粮 400；建造费用依次为 5/15/40/10/50/30/20，拆除费用 2。地块编号 200–240 被自写规则视为水域。这些是本模型的设计选择。

模型按月处理收成、粮食消费、住宅容量、迁入、劳动力、税收、维护和发展称号。邻近道路/井/集市/宗庙决定住宅等级；暂停与 1/2/3 倍速每次增加相应 tick，10 tick 为一月，保留不足一月的余数。App 的定时器间隔为 0.25 秒。无效建造不会扣款，重置清除未完成 tick；这两项及三倍速余数已在 ang 的代码中正确实现。

独立验收另发现并修复：无效地图清空现有城市；存档接受尾随字节、非法标量/建筑/住宅等级并静默归一化；载入失败修改现有状态；极端年份发生有符号溢出。现在先验证候选状态，成功才替换城市，失败保留状态与事件；年份、国库和粮食累计使用 64 位中间值并饱和到 int 上限/下限。NaN、无穷和极端有限点击坐标也有独立回归，使用既有 `map_geometry.hpp` 合同。

App 默认接入城市 HUD、网格、建造、拆除、速度和单月推进，新增“新建空城”“保存城邑”“载入城邑”。打开城市页不会自动载入地图覆盖现有城市；用户选中有效地图才开始新地图。建造失败信息在 HUD 刷新后显示；无效地图保留现有城市。无需原游戏代码即可营建空城。启动资源目录合同仍存在，用户可选自己的空目录或完全自造资源目录。

## EMP1 存档合同

EMP1 是本模型自己的格式，不兼容原游戏存档。v1 精确为 65580 字节：magic、LE32 版本、9 个 LE32 有符号字段、16384 个 LE16 地形、16384 个建筑字节及 16384 个等级字节。保存人口/容量/粮食/年份/月份/速度/繁荣度与未完成 tick；事件日志、UI 光标和建造工具属于暂态，不写入存档。

载入严格检查长度、版本、月份 1–12、速度 0–3、繁荣度 0–100、tick 0–9、非负有界人口/容量/粮食、建筑枚举、水域限制与等级。重新核算容量/等级后的完整序列化必须与输入一致，避免静默修正损坏数据。App 和独立测试共用 `city_state_io.hpp`：只读普通完整文件，拒绝符号链接；保存到同目录临时文件，写完、fsync、关闭后原子替换，错误清理临时文件。尚未做断电恢复或并发改写压力验收。

## 独立证据

`city` 的 Release/UBSan 通过，覆盖空/非法建造、重置 tick、三倍速余数、有效/无效地图、坐标边界、完整存档往返、截断/尾随/非法状态拒绝、失败不污染城市、共用文件接口错误与极值月份推进。原模型的独立失败记录和 UBSan 年份溢出日志保留在本地任务报告；测试监督器早期编译/工作目录问题另标注，不归因于产品。

现有媒体解析、默认静音/fake 音频控制、城市加媒体集成、自造 MOV 异步处理和真实终止消费者的 Release/UBSan 回归均通过。App 编译、系统框架链接、打包与 codesign strict 校验通过；未启动 GUI 或操作音频设备。GPU 读回和离线 PCM 不等于完整游戏视觉或听觉验收。AppMedia、音频后端、MovieSession 及其媒体依赖保持已有源码内容；新增的是城市接线。

```sh
python3 scripts/independent_runner.py city --mode release --output /absolute/new-output
python3 scripts/independent_runner.py city --mode undefined --output /absolute/new-output
python3 scripts/independent_runner.py integration --mode release --output /absolute/new-output
python3 scripts/independent_runner.py app --output /absolute/new-output
```

独立入口使用明确源码清单、自造输入和每个子进程 60 秒上限；保存源码、输入、二进制、结果哈希。`verify --report /absolute/report` 只核验凭据。`app` 仅构建，不启动。

## 下一步与通过标准

| 工程任务 | 具体通过标准 |
|---|---|
| 城市模型长序列与存档恢复 | 自造有效地图/操作，在多月建造、拆除、暂停和切速中维持资金/人口/容量不变量；每个中间状态保存再载入，后续相同操作得到相同模型状态；损坏存档保持旧城市；Release/UBSan 通过 |
| 图形裁剪、缩放与生命周期 | 完全自造 RGB555/RGB565/BGRA8 和独立像素 oracle，覆盖 stride、边界裁剪、缩放、重叠与 create/resize/destroy；像素逐项一致，非法输入不改输出，无失效资源引用；离屏 GPU 结果单独注明设备与误差 |
| 音视频取消与恢复 | 自造 PCM/MOV 和 fake 设备/时钟事件，覆盖队列满/空、循环、格式拒绝、恢复、seek、取消、超时和销毁；旧 epoch 回调不写入新会话，停止/释放后无遗留播放或回调，恢复保持合同；每个子进程 ≤60 秒 |

普通自写模型、组件和工程集成可以继续。原任务已被安全拦截的原城市指令恢复/差分路线不能恢复、包装重试或绕过；不读取原 EXE、反汇编、旧 Swift 或 GameData 内容，不执行原或衍生游戏库。真实 GUI、听觉、硬件恢复及原版兼容仍是独立未验证项。
