# 仓库搬粮与路网提示的最小交互草案

原生存档往返现已闭合，本页仍是待实施的交互草案。当前a43919c的core/adapter保持冻结，不重复实现另一线程交付的仓储训练关定义模块。

## 仓库搬粮

勘查仓库后显示“存粮397/600担”和“搬到另一仓”。点击后进入选仓状态，地图点击另一仓，显示其余量和可搬上限；数量默认取源库存与目标余量的较小值，允许调整。最后明确显示“从(5,2)搬100担到(10,2)，全城存粮保持397担”，点击“搬粮”提交，点击“取消”退出。

最小版采用明确的管理操作，不假装已经有道路搬运单位。目标必须是另一仓，数量必须大于0且不超过源库存/目标容量；用候选完整核验后一次提交。错误目标、仓满、取消或失败都保留全城状态。成功后勘查数字、总粮和提示同步刷新。非空仓仍拒绝拆除；搬空后才可正常拆除。暂不做多仓自动分摊或超过600担旧城的一步转换。

通过标准：自造两仓/三仓图，搬粮成功总库存精确保持、源目标分别增减同一整数、每仓不超过600；数量0/负数/超量、同仓、无效格/非仓与取消保留完整旧状态；搬空后的拆除不丢粮。真实窗口实际操作和原生保存/载入后相同操作续跑一致，旧v1/v3与既有三关回归保持。

## 路网可视提示

勘查农庄后，以描边标记其四邻接道路分量及所有可达仓，提示“通仓2座，可用余量571担”。不通时提示“农庄与仓库须各贴着同一片四邻道路”，仓满时提示“道路已通，仓库已满”；用工不足继续使用现有用工提示。颜色只辅助，文字明确原因。

建拆道路/农庄/仓库、载入或重置立即刷新，取消勘查清除标记。只标记已有四邻道路，不画穿过水域或建筑的虚构路径；多入口取可达仓并集。范围标记不改变现有产量、分配、容量或消费规则。

通过标准：斜角、无道路直邻、绕路、多入口、多分量、地图边缘和满仓图与独立四邻BFS一致；删路即时取消不可达仓，补路即时恢复；从存档恢复不残留旧城标记。有限窗口确认选中地块、文字和描边可读；先采用现有画布，缩放功能另行评估。
