# FigureFSA 缓存回引用条件分支

本次新增自写、有界、只读的字节组件。调用者必须明确选择 `cached_refs_root7b5bc8_reader4dad10`，提供已经验证的类型化缓存。它完整消费所声明的 NULL／既有对象回引用分支；**尚不支持新类声明、缓存类建对象及其动态 payload，因此不是任意 FigureFSA 的完整读取器。** 没有将组件接入实际文件资格路径，也没有读取实际数据。真实无条件边界仍为 1991913，新增实际解释字节为 0。

## 字节合同与来源

既有静态证据把所选构造 root `7b5bc8` 的 slot+8 连到 `4dad10`，其基类读取器为 `4f4480`。基类的根读取器 `40cf80` 不消费字节；不能把另一条 OldFigure7 的 `4c75c0` 当成本基类。

所有整数按小端读取；字符串是 4 字节长度与对应原始字节，内存 NUL 不在流中。组件保存区间，不猜编码或应用语义。字符串限定为非负、至多 8192 字节；输入视图至多 65536 字节。列表计数保留有符号值，非正数不迭代，正数受 256 项上限约束。拒绝超限属于现代组件的有界子集，不能推导原实现拒绝同一输入。

| 版本 | 消费顺序 |
|---|---|
| 基类 2 | 版本 word、名称、byte、3 个 State 引用、count 与 State 引用列表 |
| 基类 1 | 版本 word、名称、byte、2 个 Transition 列表、1 个 Transition 引用、2 个 Transition 列表、2 个 ActionContext 列表、1 个 State 列表、3 个 State 引用、1 个 State 列表 |
| 自身 2 | 版本 word、3 个嵌入项（各含外层 flag） |
| 自身 3、5 | 版本 word、presence byte、非零时名称、count 与名称列表、3 个嵌入项 |
| 自身 4 | 版本 word、presence byte、非零时名称、3 个嵌入项；没有名称列表 count |

嵌入构造回调 `4d7460 → 4f8930` 安装 root `7b3ee0`；其 slot+8 为 `4f8ca0`。所选自身版本 1 消费 `word + 4 DWORD = 18` 字节，外层另消费 1 字节 flag。内存步长 20 字节不等于流宽度。源 reset `4f89b0` 只写 +4/+8/+c/+10。现代组件拒绝其他嵌入版本；既有来源则对其他版本跳过 DWORD，二者不是同一个接收范围。

类型化包装分别要求 `FSAState`、`FSATransition`、`FSAActionContext`。引用 tag 为 word，`7fff` 后再读 DWORD；ID 是缓存索引。支持 NULL、重复既有对象引用及扩展索引；校验索引、class/object 种类和预先声明的 family 关系。类 schema 与对象自身版本分开。`ffff` 新类声明和带 class 高位的建对象分支在读取其 payload 前明确拒绝；后者需要独立的类型到 serializer 合同，不能按缓存命中猜流宽度。

详细结构、调用点和既有证据 SHA 见 [wire-contract.json](wire-contract.json)。这里只保存结构摘要与指纹，没有发布原始字节、反汇编全文或实际字段值。有效对象、帧、缓冲所有权、常规分配器以及受保护字段不被写入，仍是明确的正常合同；应用回调的效果和当前对象身份另列为未知，不能用普通库合同代替。

## 当前 holder+30 的最小候选

`5122c0` 返回 `[holder+30]`。调用点 `51208b` 后的 `512090/512092` 有 NULL 检查，仅非 NULL 才在 `51209d` 调用 virtual+8。presence 非零不是指针、生命周期或动态类型证明。

已命名构造链是 `510d30 → 512230 → 514500 → 512291`。在同一 holder、合法构造且对象存活到调用点的条件下，候选为 NULL 或所选 root `7b5bc8` 的对象。合法替换、重构或其他动态 root 尚未枚举；失效指针是生命周期缺口，不是另一个类候选。应用回调能否到达并改写 holder／child 尚未闭合。见 [holder30-candidates.json](holder30-candidates.json)。

因此仍有两个独立缺口：新类／建对象 payload 的广义字节合同；实际当前 holder+30 的身份、存活与 root 保持。不能因所选类和 word 匹配就推进真实无条件边界。
