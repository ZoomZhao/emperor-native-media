# 农庄路网范围与原因提示

勘查v4农庄后，黄色标记当前可达道路、青框标记可达官仓、白圈标记农庄。文字显示坐标、道路格数、去重仓数和实际余量；无可达仓解释四邻道路要求，零余量解释满仓，当前没有可用工人另行说明。余量不是该农庄保证可入仓量，共享用工、其他农庄及真实月序仍决定入仓。

只读`farmWarehouseRoute(x,y)`复用现有四邻道路分量和可达仓查询；农庄相邻多个分量取并集，官仓去重。建筑、水域和斜角不连接道路。返回行优先道路/仓格索引及实际容量、存粮、余量和当前是否有工人；非v4、非农庄或越界返回无效空结果。查询不改城市、事件、产量或运输。无缓存标记入档，不改变EMP1/ECG1版本。

勘查其他格、切换工具、进入搬粮、成功载入、新建或重置立即清标记；重新勘查农庄依据当前城重算。建拆道路/仓库、月结和库存变化经原画布刷新。当前展示可达范围和原因，不计算最短修路方案，也没有地图缩放或搬运单位。
