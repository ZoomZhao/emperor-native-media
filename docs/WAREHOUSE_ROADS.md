# 自写仓储与道路运输

在城市页点“仓储新城”，粮食会实际存入各仓。每仓容量600担；农庄和仓库必须各自贴着同一片四邻连通道路，断路收成与满仓溢出都按月记账。默认自由城和三项挑战继续用v3；v3自由城可勘查一处空陆格，再点“启用仓储”，付60贯把不超过600担的旧粮搬入一仓。已有粮食的仓库拒绝拆除。完整规则、月账上界、查询返回值和131152字节存档布局见[WAREHOUSE_ROADS_API.md](WAREHOUSE_ROADS_API.md)。
