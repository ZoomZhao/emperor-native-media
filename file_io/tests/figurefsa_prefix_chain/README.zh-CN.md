使用既有六类的自造夹具，加六组前缀接续检查。最终两模式各28/0；原 API 另两模式各14/0。6020 是此样本的缓存上下文，现代8192/1024/128/16等预算不冒称原实现限制。

```sh
python3 file_io/tests/figurefsa_prefix_chain/run.py --output /absolute/new-output-directory
```

输出目录必须不存在。Clang depfile 记录实际编译依赖。单次编译≤40秒、自写测试≤20秒；无原输入、游戏、设备或转换产物。真实条件样本单独见 [报告](../../../docs/city19-figurefsa-shared-prefix-chain-20261012/README.zh-CN.md)，其失败不计入正常合成通过数。
